# Governança Técnica Ideavelo — v1.0

Esta pasta contém as políticas corporativas e as decisões arquiteturais aprovadas em 2026-11-07.

- `governance/`: nomenclatura, titularidade, catálogo e infraestrutura.
- `architecture/`: integração com Factory, plugins e serviços compartilhados.
- `decisions/`: ADRs imutáveis historicamente; mudanças posteriores devem criar ADR substituta ou registrar supersessão.

A documentação não cria infraestrutura nem altera repositórios de produtos. Para mudanças, abrir PR com impacto, migração e aprovação. O Registry da Factory é a fonte operacional de verdade; este repositório define a política.
