## Princípios

Um plugin comercial por plataforma, com identidade, escopos, versionamento, publicação e ciclo de vida independentes. MCP é protocolo técnico, não categoria comercial. Produtos são de propriedade `internal`. A plataforma compartilhada não deve tornar os plugins monolíticos nem impedir evolução independente.
