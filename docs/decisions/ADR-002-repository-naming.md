# ADR-002 — Nomenclatura GitHub

- **Status:** Aceita
- **Data:** 2026-11-07

## Decisão
Usar `{propriedade}-{categoria}-{produto}` para novos produtos e `customer-{categoria}-{cliente}-{produto}` quando for necessário identificar o cliente. Categoria comercial `plugin`, tecnologia `mcp` em metadados e implementação.

## Consequências
Repositórios são planos no GitHub; nomes e topics permitem filtro. Não renomear repositórios legados automaticamente.
