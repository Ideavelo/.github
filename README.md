## Technology ecosystem

Ideavelo develops AI-enabled software products and internal platforms. Technologies used across parts of the ecosystem include **.NET, React, Next.js, TypeScript, PostgreSQL, Docker, Coolify, GitHub Actions, Keycloak, MCP and LLM APIs**.

Technology choices and versions are **repository-specific**. Consult each project's source manifests, documentation and deployment configuration for authoritative requirements.

## Engineering principles

- **Security by design:** least privilege, environment isolation, secret management and secure defaults.
- **Human-governed autonomy:** bounded agent permissions, independent approvals for sensitive operations and auditable decisions.
- **Cost control:** explicit inference budgets, provider controls and reliable usage accounting.
- **Quality and traceability:** focused changes, automated checks, reproducible evidence and peer review.
- **Reliable operations:** staged deployments, observability, incident response and recovery planning.
- **Sustainable architecture:** maintainable components, clear contracts and incremental evolution.

See the [engineering standards](docs/ENGINEERING.md) for detailed recommendations.
